# Protocol Scout

AI-powered Web3 protocol discovery and research toolkit.

Protocol Scout helps users discover, analyze, and compare Web3 protocols through structured research workflows.

## What it does

* Discover Web3 protocols
* Collect protocol information
* Analyze projects with AI
* Generate structured research reports
* Compare protocols across multiple dimensions
